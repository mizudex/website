# website
Github provide a free hosting website; Pages: assigned to branch, so in theory you can have as many website as you like in that branch, providing more flexibility. It's not limited to the name of the repository, so if one have the name of the repository like "website", it simply directed to https://<username>.github.io/<repository-name>. Github also provide some sort of hosting plan, so github.io name could be removed.

What makes a website, website? Generally, it's HTML, CSS, and JavaScript. And Github have it all of those three hosted on them natively. Though, it is only, in fact, the standard to make a website. Security is out of the question if there is only these three present, could we improve it while still on this domain?
